# MoodBoard

An addictive daily visual inspiration app where users create and share beautiful mood boards from curated images. Each day presents a new theme (e.g., 'Serenity', 'Urban Jungle', 'Vintage Dreams') and users drag & drop images to create their perfect mood board composition. Users can like and share others' creations, compete for daily featured spots, and build a following.

Key Features:
- Daily changing themes with fresh image sets
- Drag & drop interface
- Social sharing & likes
- Daily leaderboard
- Progressive achievements

Tech Stack:
- HTML5 Canvas & Drag/Drop API
- CSS Grid & Animations
- Vanilla JavaScript
- LocalStorage for persistence
